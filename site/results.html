Results

400,000 simulated games: the snake and standard drafts, each played on 100,000 separated boards and 100,000 random boards. Every margin below is a 95% confidence interval of ±0.01 points or less, so the differences are real for these players.

All four players are greedy computer players: each turn they take the open spot worth the most right now. Payoff = the dice weights around a player's two settlements, i.e. expected production, not actual resources. Snake and standard play the same boards (same seeds), so the draft order is the only difference between them.

Fairness gap = highest seat average minus lowest. Avg spread = best minus worst payoff inside one game, averaged over all games.

1. Why snake nearly evens things out

  • Picking earlier gets a better first spot: A 12.47, B 11.75, C 11.15, D 10.55.
  • Snake reverses the order for the second pick, so D (two picks in a row) gets the best leftover and A the worst: A 8.24, B 8.80, C 9.38, D 9.97.
  • The two almost cancel. A's first-pick lead over D (1.92) is a little bigger than D's second-pick lead over A (1.73), so A keeps a small edge of 0.19 points.

2. Snake vs standard on the same boards

  • Standard is a strict ladder: A 22.44 > B 21.14 > C 19.94 > D 18.80.
  • Game by game on the same boards, snake shrinks the best-vs-worst spread by 2.16 ± 0.007 points (separated boards) and 2.57 ± 0.008 (random boards).
  • Under standard, seat A can never score below anyone. Greedy pick values never go up (good spots only disappear), so each of A's picks beats B's, B's beat C's, and so on. A finished first, alone or tied, in all 100,000 games.
  • Both drafts take the exact same eight spots in the same order. The draft only decides who gets each one, which is why the second-pick values in the two drafts are the same four numbers handed to opposite seats.

3. Separated vs random boards

  • Keeping 6s and 8s apart cuts the snake gap from 0.88 to 0.19, about four times smaller, and the within-game spread from 1.89 to 1.48.
  • It helps under standard too (4.46 to 3.64), but standard stays far less balanced.
  • Likely reason: on random boards, 6s and 8s can sit together and form one very strong spot. A's first pick is worth 13.39 there against 12.47 on separated boards, while the later seats' picks barely change.

Where players settle

  • Coast corners touch only one or two tiles and are almost never taken.
  • The most-taken spots, about 37% of games each, form a ring around the centre hex rather than sitting on the centre hex's own corners. One possible reason: the centre corners are close together, so one settlement there blocks several others. Not yet checked.

Reproduce

Rebuild every number and chart (about 5 minutes; same seeds give the same games):

python main.py experiments --games 100000 --seed 0

Replay any single game from the raw data by its seed, for example:

python main.py play --seed 0 --board separated --draft snake

Limits. These results describe greedy players, a simple heuristic, not equilibrium play. Players who think ahead or block on purpose could change the picture, and then the draft order would also change which spots get taken. The fairness gap is one measure of balance between seats, not proof that a draft is fair in every sense.

Quentin Drucker and Emmett Manning, COM313 Algorithmic Game Theory, Prof. Christine Chung
